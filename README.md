# Book Haven

Book Haven is a simple e-commerce bookstore built using React.js. It allows users to browse books, search for products, filter books by category, sort them, add books to a cart, and proceed to checkout.

## Technologies Used

- React.js
- JavaScript
- HTML5
- CSS3
- React Hooks
- React Router

## Features

- Browse books
- Search books
- Category filtering
- Book sorting
- Shopping cart
- Checkout page
- Responsive and simple user interface
